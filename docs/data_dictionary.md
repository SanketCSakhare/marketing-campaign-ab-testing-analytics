# Data Dictionary

| Field | Definition |
| --- | --- |
| `campaign_name` | Experiment treatment: control or test |
| `date` | Campaign reporting date |
| `spend_gbp` | Daily media spend in GBP |
| `impressions` | Number of ad displays |
| `reach` | Estimated unique users exposed |
| `website_clicks` | Clicks from an ad to the website |
| `searches` | On-site searches following a visit |
| `content_views` | Product or content detail views |
| `add_to_cart` | Add-to-cart events |
| `purchases` | Completed purchases |

Derived KPIs include click-through rate (CTR), click-to-purchase conversion, cost per click (CPC), and cost per acquisition (CPA).
